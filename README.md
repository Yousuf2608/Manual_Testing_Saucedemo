# Manual_Testing_Saucedemo

## 📌 Project Overview

This repository contains a comprehensive **Manual Testing** project for the **SauceDemo** e-commerce web application. The project demonstrates the software testing lifecycle by designing and executing functional test cases, documenting test results, and reporting identified defects.

The objective of this project is to validate the core functionalities of the application and identify usability or functional issues through structured manual testing.

---

## 🌐 Application Under Test

**Website:** https://www.saucedemo.com/

---

## 📋 Project Scope

The testing covered the following modules:

- Login Functionality
- Product Page
- Product Details Verification
- Add to Cart
- Cart Validation
- Checkout Process
- Product Filter
- Continue Shopping
- Logout
- About Navigation
- Reset App State

---

## ✅ Test Coverage

A total of **14 functional test cases** were created and executed, covering both positive and negative test scenarios.

### Login Testing
- Valid login
- Blank username and password

- Invalid username

### Product Testing
- Product page navigation
- Product details verification
- Add to Cart functionality

---

## 🐞 Defect Reports

The project includes **4 documented defects**, including:

- Locked-out user login issue
- Unable to increase product quantity
- Reset App State not functioning correctly
- Social media links not working

Each defect report contains:
- Bug ID
- Bug Title
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status
